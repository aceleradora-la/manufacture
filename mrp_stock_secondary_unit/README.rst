Usage
=====

This module works automatically when you have `mrp_production_secondary_unit` installed.

When a manufacturing order is confirmed, the secondary unit information is automatically transferred to:

* Finished product stock moves
* Raw material stock moves
* Byproduct stock moves

The secondary unit and quantity will be visible in the stock move form view.
