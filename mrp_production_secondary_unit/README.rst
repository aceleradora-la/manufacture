Usage
=====

To use this module, you need to:

1. Go to *Manufacturing > Operations > Manufacturing Orders*.
2. Create or edit a manufacturing order.
3. Select a product that has a secondary unit of measure configured.
4. The secondary unit and quantity will be automatically calculated based on the primary quantity and conversion factors.

The module supports:

* Main finished product in production orders
* Raw materials (components) in production orders
* Byproducts in production orders
